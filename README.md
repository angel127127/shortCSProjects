# Short Cybersecurity projects

Welcome to my collection of personal cybersecurity-related projects! The purpose of these projects is to extended and develop my understanding of security concepts and cybersecurity in general.

## Current projects
- Password Strength Checker - analyses password complexity and uses an API to check if password has been pwned. 

- Port Scanner - simple scanner to idetify open ports. 

Developed using Python 3.13. 
These projects have been made for educational use. 
Each project has a README.md to explain the purpose of it and the results. 
To get started, clone the repository and cd into a specific project.
